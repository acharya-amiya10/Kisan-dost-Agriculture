# 🌾 Kisan Dost - Realtime Agriculture App

An interactive, responsive frontend web application built using **React** and **TypeScript**, powered by **Vite** for optimized performance and **Firebase** for realtime data syncing.

## 🚀 Technical Highlights & Solved Challenges
* **TypeScript Integration:** Leveraged strict typing across components and data layers to eliminate runtime errors and state mismatches.
* **Vite Optimization:** Engineered with Vite for ultra-fast Hot Module Replacement (HMR) and optimized production bundles.
* **Firebase Backend-as-a-Service:** Configured Firestore security rules and initialized real-time database listener architectures.
* **Modern State Architecture:** Managed async data streams efficiently using functional hooks (`useState`, `useEffect`) without unnecessary re-renders.

## 🛠️ Tech Stack
* **Frontend:** React, TypeScript, Vite
* **Backend/Database:** Firebase (Firestore, Config Architecture)
* **Tooling:** npm, Git

## 💻 How to Run Locally
1. Clone the repository.
2. Run `npm install` to set up node modules.
3. Configure your local `.env` variables using the `.env.example` template.
4. Run `npm run dev` to launch the local development server.
